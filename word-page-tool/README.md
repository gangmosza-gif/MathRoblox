# ตัวช่วยจัดหน้า Word (ออฟไลน์)

โปรแกรมไฟล์เดียว (`index.html`) สำหรับไฟล์ `.docx` — ดับเบิลคลิกเปิดในเบราว์เซอร์ (Chrome / Edge / Firefox รุ่นใหม่) ได้ทันที ไม่ต้องติดตั้ง ไม่ต้องต่ออินเทอร์เน็ต

## ทำอะไรได้บ้าง
| ความสามารถ | รายละเอียด |
|---|---|
| ลายน้ำเฉพาะหน้า | เลือกหน้าได้อิสระ (เช่น `2-5, 8`, หน้าคี่/คู่, ยกเว้นหน้าแรก) เลือกข้อความ ฟอนต์ ขนาด (หรืออัตโนมัติพอดีหน้า) ตัวหนา/เอียง สี ความจาง มุมเอียง และตำแหน่ง 9 จุด |
| เลขหน้าเฉพาะหน้า | รูปแบบ `{n}`, `หน้า {n}`, `หน้า {n} จาก {total}` หรือพิมพ์เอง • ใช้เลขหน้าจริง (Word อัปเดตเอง) หรือนับใหม่เฉพาะหน้าที่เลือก • เลขอารบิก/เลขไทย • ฟอนต์ ขนาด สี ตำแหน่ง 6 จุด และระยะจากขอบ |
| แนวกระดาษรายหน้า | ตั้งหน้าใดก็ได้เป็นแนวตั้ง/แนวนอน |
| ภาพตัวอย่าง | เห็นทุกหน้าเป็นภาพย่อ + หน้าขยาย พร้อมป้ายบอกว่าหน้านี้จะมีอะไรเปลี่ยน และสรุปการเปลี่ยนแปลงก่อนบันทึก |

## ข้อความไม่ขยับ — ทำอย่างไร
- **ลายน้ำ/เลขหน้า** ใส่เป็น “วัตถุลอย ไม่ตัดข้อความ” (ลายน้ำอยู่หลังข้อความ) จึงไม่ดันหรือเลื่อนตัวอักษรเดิม และไม่แก้ส่วนหัว/ท้ายกระดาษเดิม
- โปรแกรมอ่านตำแหน่งตัดหน้าที่ Word บันทึกไว้ในไฟล์ แล้วยึดวัตถุกับย่อหน้าแรกที่เริ่มในหน้านั้น
- **หลังบันทึก โปรแกรมตรวจซ้ำอัตโนมัติ** ว่าข้อความทุกตัวอักษรตรงกับต้นฉบับ และส่วนอื่นของไฟล์ (รูป สไตล์ ส่วนหัว/ท้าย) ถูกคัดลอกมาแบบไบต์ต่อไบต์
- การเปลี่ยนแนวกระดาษต้องใช้ตัวแบ่งส่วน (Section Break) ของ Word ข้อความในหน้าอื่นไม่ถูกแตะ แต่ข้อความ *ในหน้าที่หมุน* จะจัดบรรทัดใหม่ตามความกว้าง (เป็นธรรมชาติของ Word) โปรแกรมจะแจ้งล่วงหน้าหากหน้านั้นเริ่มกลางย่อหน้าหรือกลางตาราง

> แนะนำ: ถ้าไฟล์มาจากโปรแกรมอื่น (Google Docs, LibreOffice) ให้เปิดใน Microsoft Word แล้วกด **Ctrl+S** หนึ่งครั้งก่อน เพื่อให้มีข้อมูลตำแหน่งหน้าที่แม่นยำ

## ความปลอดภัย
- **ไม่ส่งข้อมูลออกนอกเครื่อง**: หน้าเว็บถูกล็อกด้วย Content-Security-Policy (`connect-src 'none'` ฯลฯ) เบราว์เซอร์จะบล็อกการเชื่อมต่อเครือข่ายทุกชนิด ตรวจได้เองโดยเปิด DevTools → แท็บ Network จะไม่มีรายการใด ๆ
- **ไม่มีโค้ดจากภายนอก**: ไม่ใช้ไลบรารี/CDN/ฟอนต์ออนไลน์ ตัวอ่าน-เขียน ZIP เขียนเองในไฟล์ ตรวจสอบได้ทั้งหมด
- **ไม่เก็บข้อมูล**: ไม่ใช้คุกกี้หรือ localStorage ปุ่ม “ล้างข้อมูล” ลบไฟล์ออกจากหน่วยความจำทันที
- **ตรวจไฟล์ก่อนเปิด**: ปฏิเสธไฟล์มาโคร (.docm), XML ที่มี DOCTYPE/ENTITY, zip bomb, ไฟล์เสีย/ซ้ำซ้อน และแจ้งเตือนลิงก์ภายนอกที่โหลดอัตโนมัติ (อาจใช้ติดตามผู้เปิดไฟล์)
- **แสดงข้อความจากไฟล์อย่างปลอดภัย** (ใช้ `textContent` ไม่ใช้ `innerHTML`) ป้องกันโค้ดแฝงในเอกสาร
- **ลบ Metadata ได้**: ตัวเลือกลบชื่อผู้สร้าง/ผู้แก้ไข/บริษัท ออกจากไฟล์ผลลัพธ์
- ไฟล์ต้นฉบับไม่ถูกแก้ไข — ได้ไฟล์ใหม่เสมอ

## ข้อจำกัด
- รองรับ `.docx` เท่านั้น (ไม่รองรับ `.doc` รุ่นเก่า / ไฟล์ที่ตั้งรหัสผ่าน)
- ภาพตัวอย่างเป็นการจำลองโดยประมาณ การตัดบรรทัดจริงขึ้นกับ Word
- เลขไทยแบบ “เลขหน้าจริง” (`\* ThaiArabic`) แสดงผลใน Microsoft Word; LibreOffice แสดงเป็น ก ข ค — ถ้าต้องใช้หลายโปรแกรม เลือกแบบ “นับใหม่”
- เปลี่ยนแนวกระดาษหน้าที่เริ่ม **กลางย่อหน้าที่จัดชิดขอบสองด้าน**: บรรทัดสุดท้ายก่อนตัดหน้าจะชิดซ้าย (ตัวอักษรครบ ไม่ขึ้น/ลง)
- หน้าที่ **เริ่มกลางตาราง**: Word เปลี่ยนแนวกลางตารางไม่ได้ ทั้งตารางจะอยู่ฝั่งแนวนอน หน้าหลังจากนั้นอาจจัดใหม่
- หน้าที่ **เป็นตารางทั้งหน้า** หรือ **เป็นย่อหน้าเดียวยาวทั้งหน้า**: ลายน้ำ/เลขหน้ายึดได้ไม่สมบูรณ์ในบางโปรแกรม โปรแกรมจะเตือนให้ตรวจใน Word

## ผลการทดสอบอัตโนมัติ
ทดสอบ 51 ชุดการตั้งค่า บนไฟล์ทดสอบ 5 แบบ (ตัวแบ่งหน้า, ข้อความไหลยาว, หลาย section แนวตั้ง/นอน + เริ่มนับเลขใหม่, ลิงก์/Track Changes/Content Control/รูป/เชิงอรรถ, ไฟล์ที่เคยผ่านโปรแกรมแล้ว) รวมชุดสุ่มค่า 36 ชุด
เรนเดอร์ต้นฉบับและผลลัพธ์เป็น PDF แล้วเทียบตำแหน่ง **ทุกตัวอักษรในทุกหน้า**: หน้าที่ไม่ได้เปลี่ยนแนวกระดาษ ตัวอักษรเคลื่อน 0.000pt, ลายน้ำ/เลขหน้าอยู่เฉพาะหน้าที่เลือก ฟอนต์ ขนาด ตำแหน่งตรงตามตั้งค่า (ทดสอบด้วย LibreOffice; ยังไม่ได้ทดสอบกับ Microsoft Word โดยตรง)

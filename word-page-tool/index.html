ตัวช่วยจัดหน้า Word ใส่ลายน้ำ • ใส่เลขหน้า • เปลี่ยนแนวกระดาษ — เฉพาะหน้าที่เลือก
🔒 ทำงานในเครื่องนี้เท่านั้น — ไม่มีการส่งข้อมูลออก
1. เปิดไฟล์โปรแกรมแสดงทุกหน้าให้เห็นเป็นภาพย่อ
2. เลือกหน้าติ๊กหน้าที่ต้องการ หรือพิมพ์ เช่น 1-3, 5
3. ตั้งค่าลายน้ำ / เลขหน้า / แนวกระดาษ พร้อมดูภาพตัวอย่างทันที
4. บันทึกได้ไฟล์ใหม่ พร้อมผลตรวจว่าข้อความไม่ถูกแก้ไข

🛡️ ความปลอดภัยของโปรแกรมนี้

  • ไม่ส่งข้อมูลออกนอกเครื่อง — หน้าเว็บถูกล็อกด้วย Content-Security-Policy ห้ามเชื่อมต่อเครือข่ายทุกชนิด (ใช้งานโดยไม่ต่ออินเทอร์เน็ตได้ 100%)
  • ไม่มีโค้ดจากภายนอก — ทุกอย่างอยู่ในไฟล์นี้ไฟล์เดียว ไม่โหลดไลบรารี/ฟอนต์/รูปจากอินเทอร์เน็ต ตรวจสอบโค้ดได้ทั้งหมด
  • ไม่เก็บข้อมูลไว้ — ไม่ใช้คุกกี้ ไม่บันทึกลงเครื่อง ปิดแท็บหรือกด “ล้างข้อมูล” แล้วข้อมูลหายทันที
  • ตรวจไฟล์ก่อนใช้งาน — แจ้งเตือนมาโคร ลิงก์ภายนอกที่อาจใช้ติดตามผู้เปิดไฟล์ และป้องกันไฟล์อันตราย (zip bomb, XML แปลกปลอม)
  • ไม่แก้เนื้อหา — ลายน้ำและเลขหน้าเป็นวัตถุลอยแบบ “ไม่ตัดข้อความ” ข้อความเดิมจึงไม่ขยับ และตรวจซ้ำหลังบันทึกว่าตัวอักษรครบเหมือนต้นฉบับ
